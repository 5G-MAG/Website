## What a blueprint is here

An **Implementation Blueprint** is a specific section within a [Technology & Analysis](/tech) page: a table that walks through a procedure step by step (for example, everything a UE does to acquire and decode a broadcast service), and for each step names the protocol layer involved, the mechanism 5G-MAG's analysis found, and the exact 3GPP clause it comes from. It sits inside the page's normal analysis prose rather than as a separate page type — the same page explains *why*, the blueprint section is the *in-order how*.

This is 5G-MAG's own framing, echoed in the "Profiles and Blueprints" language used to describe this portal's mission, not an externally defined 3GPP or ISO deliverable type; there is no formal industry definition of "implementation blueprint" to cite here.
