<h1>5G Media Streaming (5GMS)</h1>
</div>

:::tip[At a glance]

- **Functions:** the 5GMS Application Provider, AF and AS, and on the device the 5GMS Client, with a Media Session Handler and a Media Player (downlink) or Media Streamer (uplink).
- **In the 5G System:** the AF and AS are data network functions that reach the device over N6. The AF reaches 5G Core functions directly from a trusted data network, or through the Network Exposure Function from an external one.
- **Releases:** first version in Release 16; delivery via eMBMS in Release 17; delivery via MBS, Service URL handling and TS 26.510 in Release 18; Advanced Media Delivery in Releases 19 and 20.

:::

## The main functions

<SpecFigure src="/img/tech/5gms/generated/ts26501-fig4.1.1-2.svg" width={1200} height={551} spec="TS 26.501 V19.4.0" figure="4.1.1-2" title="5G Media Streaming general architecture" alt="The 5GMS Client in the UE, with its Media Session Handler and Media Stream Handler, and the 5GMS-Aware Application; the 5GMS AF and 5GMS AS in the DN with the 5GMS Application Provider; NEF and PCF connected to the AF over N33 and N5; reference points M1 to M8, M11 and M13." />

- **5GMS Application Provider:** uses 5GMS for its streaming services, and provides a 5GMS-Aware Application on the device.
- **5GMS Application Function (AF):** an Application Function dedicated to 5G Media Streaming. It provides control functions to the Media Session Handler on the device and to the Application Provider.
- **5GMS Application Server (AS):** an Application Server dedicated to 5G Media Streaming. In downlink it streams media to the Media Player; in uplink it receives media from the Media Streamer.
- **5GMS Client:** a function inside the device dedicated to 5G Media Streaming. It has a Media Session Handler and, in downlink, a Media Player or, in uplink, a Media Streamer.

## Where it sits in the 5G System

The AF and the AS are data network functions that communicate with the device over the N6 reference point. An AF in the operator's trusted data network may communicate directly with the relevant 5G Core functions, for example the Policy and Charging Function (PCF). An AF in an external data network may only reach 5G Core functions through the Network Exposure Function.

## How it grew

- **Release 16:** the first version of the architecture, procedures and APIs.
- **Release 17:** work items on edge extensions and AF event exposure, studies on multicast and on further 5GMS extensions, and delivery via eMBMS (added to TS 26.501 in version 17.1.0).
- **Release 18:** work items on 5G Media Streaming Architecture Phase 2 and Protocols Phase 2. Service URL handling and delivery via MBS are added. TS 26.510 is created, and with it media delivery is harmonised across 5GMS and Real-Time media Communication (RTC). TS 26.501 adds a generalised Media Delivery architecture.
- **Release 19:** Advanced Media Delivery. 3GPP justified its study by the importance of mobile media delivery, with continued traffic growth and new functions from third-party service providers.
- **Release 20:** Advanced Media Delivery Phase 2, which continues the study of extensions beyond the Release 19 normative work.

The Technical Analysis pages show what each release added, from Release 16 to Release 19.
