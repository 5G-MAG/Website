## What a specification page is here

Every [Technology & Analysis](/tech) page carries its own **Specifications** page: the full, maintained list of the standards documents behind that page's analysis, layer by layer, kept separate from the analysis prose so the spec list can be updated (a new release, a corrected clause reference) without touching the analysis itself. These pages are served under `/standards/<topic>` URLs for routing reasons, not because they belong to the Standardisation pillar — [Standardisation](/standards) is 5G-MAG's own participation in the standards process (feedback, requirements, liaison statements); a topic's specification list is Tech content, indexed here.

This index gathers all of them in one place, the same way [Implementation Blueprints](/tech/blueprints) gathers the subset of Analysis pages with a step-by-step procedure section — neither is a resource in its own right; each is a specific facet of the same 16 Analysis pages, pulled out into its own view because a reader sometimes wants just that facet across every topic at once.
