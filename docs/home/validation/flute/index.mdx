:::tip[At a glance]

- **What it is:** a validator that tests a FLUTE implementation against the FLUTE profiles of IETF RFC 3926, 3GPP TS 26.346 and 3GPP TS 26.517.
- **What it tests:** rt-libflute, the FLUTE library of the Content Delivery Protocols and Tools, in a version you choose.
- **What a verdict means:** it is a first version, built from a reading of the documents. No independent party has verified it yet.

:::

## What it does

FLUTE (File Delivery over Unidirectional Transport, IETF RFC 3926) is used by 3GPP MBMS (TS 26.346) and MBS (TS 26.517) to deliver files. Each of these documents defines a profile: the values a sender may use and what a receiver must accept. The validator checks an implementation against those profiles.

For each profile it configures the library's transmitter with the values the profile supports, reads the packets on the wire with its own decoder, runs the library's receiver on the same session, and sends what the transmitter cannot be made to send, such as unknown extensions or invalid packets, to check that the receiver handles it as the profile requires. The result lists every failed "shall", every "should" that is not met, and the verdict on each normative statement of the profile's documents. [How it works](./implementation) describes the method.

## Profiles

| Profile | Rests on | Releases |
| --- | --- | --- |
| `Profile::None` | IETF RFC 3926 | none |
| `Profile::MBMS::Download` | 3GPP TS 26.346 annex L.4 | 13 to 19 |
| `Profile::MBS` | 3GPP TS 26.517 clause 6.2 | 17 to 19 |

Each 3GPP profile is tested per release, against the latest edition of that release. Release 20 has no edition of either document yet (October 2026). [Implementation Detail](./implementation) lists the editions.

## Where it stands

The validator tests rt-libflute only: its two test harnesses are built against the library's own interface, although the checks of the packets on the wire do not depend on the library. The reference it checks against is a reading of the documents, recorded in the repository, not a test specification published by 3GPP or the IETF. Some statements cannot be checked, for example those that oblige the network or the application, and each is listed with its reason.

The repository is available on request; see [Early Access](/early-access).
