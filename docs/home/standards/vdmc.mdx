## Overview

5G-MAG tracks ISO/IEC 23090-29 (Video-based Dynamic Mesh Coding, V-DMC), from ISO/IEC JTC 1/SC 29/WG 7 (Coding of 3D Graphics and Haptics). It compresses 3D meshes whose geometry, connectivity and attributes change per frame, using a simplified "basemesh" plus per-frame displacement and existing video codecs (HEVC, VVC). For the standardisation-stage history behind this specification, see [Standards Evolution](/standards/vdmc/evolution).
