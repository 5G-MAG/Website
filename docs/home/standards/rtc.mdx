<h1>Real-time Media Communication (RTC) Architecture</h1>
</div>
</div>

Real-time media communication over the 5G System is specified by 3GPP SA4. This page lists its specifications and what each covers.

The page covers Release 18 and Release 19. Two Release 20 work items in the 3GPP work plan list TS 26.506 or TS 26.113, on application energy consumption reporting; their changes are not covered here.

:::tip[At a glance]

- **Specified by:** 3GPP SA4.
- **Two specifications:** TS 26.506 (architecture, stage 2) and TS 26.113 (procedures, APIs and protocols, stage 3).
- **Shared with 5G Media Streaming:** the provisioning and media session handling APIs are defined once, in TS 26.510, for both 5GMS and RTC. TS 26.113 uses a subset of them.
- **By release:** all three are created in Release 18. Release 19 adds PDU handling and marking enhancements, media capability and metadata support, and the M13 reference point in the generalised architecture.
- **Built on:** the 5G System (TS 23.501), the 5GMS architecture (TS 26.501), and the WebRTC protocols of the IETF.

:::

## Specifications

The Release column is the release of each document's first version. Titles are each document's cover title; the last column summarises its Scope clause.

| Specification | Title | Release | Covers |
| --- | --- | :---: | --- |
| [TS 26.506](https://www.3gpp.org/dynareport/26506.htm) | 5G Real-time Media Communication Architecture (Stage 2) | 18 | An architecture for real-time media communication integrated into the 5G System, based on the 5GMS architecture: functions, reference points, collaboration scenarios between the 5G System operator and third-party providers, and call flows |
| [TS 26.113](https://www.3gpp.org/dynareport/26113.htm) | Real-Time Media Communication; Protocols and APIs | 18 | The stage 3 procedures, APIs and protocols for the reference points of the RTC architecture, for WebRTC-based real-time media transport over 5G |
| [TS 26.510](https://www.3gpp.org/dynareport/26510.htm) | Media delivery; interactions and APIs for provisioning and media session handling | 18 | The provisioning and media session handling APIs common to 5G Media Streaming and RTC |

TS 26.113 refers to TS 26.510 for the general aspects and deals with the RTC-specific ones. Its provisioning API is a subset of the TS 26.510 provisioning APIs, and its media session handling API a subset of the TS 26.510 session handling APIs.

## IETF and W3C documents

RTC is based on WebRTC. These are the documents TS 26.113 and TS 26.506 make normative use of, with titles as in their reference lists.

| Document | Title | For |
| --- | --- | --- |
| [RFC 8825](https://datatracker.ietf.org/doc/html/rfc8825) | Overview: Real-Time Protocols for Browser-Based Applications | The correspondence of RTC Applications to WebRTC browser and non-browser endpoints |
| [RFC 8834](https://datatracker.ietf.org/doc/html/rfc8834) | Media Transport and Use of RTP in WebRTC | Media transport, and packet-loss handling for video |
| [RFC 8835](https://datatracker.ietf.org/doc/html/rfc8835) | Transports for WebRTC | Transport protocols, and packet-loss handling for video |
| [RFC 5124](https://datatracker.ietf.org/doc/html/rfc5124) | Extended Secure RTP Profile for Real-time Transport Control Protocol (RTCP)-Based Feedback (RTP/SAVPF) | The RTP profile for audio, video and speech |
| [RFC 3711](https://datatracker.ietf.org/doc/html/rfc3711) | The Secure Real-time Transport Protocol (SRTP) | Encapsulation of encoded media |
| [RFC 8831](https://datatracker.ietf.org/doc/html/rfc8831) | WebRTC Data Channels | Application data and metadata |
| [RFC 8261](https://datatracker.ietf.org/doc/html/rfc8261) | Datagram Transport Layer Security (DTLS) Encapsulation of SCTP Packets | The data channel transport |
| [RFC 8829](https://datatracker.ietf.org/doc/html/rfc8829) | JavaScript Session Establishment Protocol (JSEP) | The state machine the SWAP signalling protocol adheres to |
| [RFC 7807](https://datatracker.ietf.org/doc/html/rfc7807) | Problem Details for HTTP APIs | SWAP error messages |
| [WebRTC](https://www.w3.org/TR/webrtc/) | WebRTC: Real-Time Communication in Browsers (W3C) | The JavaScript APIs to which the RTC-7 procedures are equivalent |

TS 26.113 states that the audio and video codec requirements of RFC 7874 and RFC 7742 do not apply to RTC endpoints.
