<h1>Real-time Media Communication (RTC)</h1>
</div>
</div>

Real-time media communication over the 5G System is specified by 3GPP SA4. This page lists its specifications and what each covers.

For the moment the RTC work is focused on 5G-RTC, the architecture of TS 26.506 and the protocols of TS 26.113 (which share the provisioning and media session handling APIs of TS 26.510 with 5G Media Streaming), and, in parallel, on SWAP, the signalling protocol of TS 26.113 clause 13.2.4.

The page covers Release 18 and Release 19. Two Release 20 work items in the 3GPP work plan list TS 26.506 or TS 26.113, on application energy consumption reporting; Release 20 (work plan of 28 September 2026): Energy_ARCH-MED (100%, finish 9 September 2026) is reflected in TS 26.506 V20.0.0 by CR 0013, and Energy_PRO-MED (0%, planned 3 March 2027) lists TS 26.113. The study FS_Q4RTC_MED on QUIC-based media delivery for real-time communication (TR 26.836, 42%) is listed in [Release history](/standards/rtc/evolution). The Release 20 changes themselves are not covered here.

:::tip[At a glance]

- **Specified by:** 3GPP SA4.
- **Two RTC specifications:** TS 26.506 (architecture, stage 2) and TS 26.113 (procedures, APIs and protocols, stage 3), plus the shared TS 26.510.
- **Shared with 5G Media Streaming:** the provisioning and media session handling APIs are defined once, in TS 26.510, for both 5GMS and RTC. TS 26.113 uses a subset of them.
- **By release:** all three are created in Release 18, together with TS 26.522 (5G_RTP), which TS 26.113 uses for SDP attributes and PDU Set semantics. Release 19 adds PDU handling and marking enhancements (5G_RTP_Ph2, in TS 26.522, TS 26.510 and TS 26.113), media capability and metadata support, and the M13 reference point in the generalised architecture.
- **Built on:** the 5G System (TS 23.501), the 5GMS architecture (TS 26.501), and the WebRTC protocols of the IETF.

:::

TS 26.113 refers to TS 26.510 for the general aspects and deals with the RTC-specific ones. Its provisioning API is a subset of the TS 26.510 provisioning APIs, and its media session handling API a subset of the TS 26.510 session handling APIs.
