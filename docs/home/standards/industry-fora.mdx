## Overview

Besides its liaison with 3GPP, MPEG and ETSI (see [Liaison Statements & Inputs](/ls)), the 5G-MAG Project Office takes part in other industry fora and open projects whose work meets 5G-MAG's projects. This page lists those contributions so members can see where the Project Office speaks for 5G-MAG, and can join in.

The links go to the public records of each forum. Contributions that have no public record are listed without a link and are marked as such.

## CAMARA (Linux Foundation)

5G-MAG's [Network APIs](/tech/network-apis) work builds on the CAMARA Network APIs. The Project Office contributes to two CAMARA working groups.

| Year | Forum | Contribution | Record |
| ---- | ----- | ------------ | ------ |
| 2026 | CAMARA Connectivity Quality Management | Two pull requests on the white paper (the booking and session distinction and the API family structure, and typo corrections), and comments on ten others about QoS Profile terminology, API versions and the meta-release reference, the diagram captions and the appendix structure | [Pull requests #13 and #14, comments on #6, #8, #12, #18, #24 to #28 and #31](https://github.com/camaraproject/ConnectivityQualityManagement/pulls?q=is%3Apr+is%3Aclosed) |
| 2026 | CAMARA Dedicated Networks | Fixes to the global paths and tags of the dedicated-network profiles and areas | [Pull requests #106 and #117](https://github.com/camaraproject/DedicatedNetworks/pulls?q=is%3Apr+is%3Aclosed) |
| 2025 | CAMARA Dedicated Networks | Comment on the definition of "Max Number of Devices" in the network profile | [Issue #85](https://github.com/camaraproject/DedicatedNetworks/issues/85) |

## MPEG: glTF Validator

The glTF Validator checks glTF 3D scenes. The MPEG extensions used by [XR Media and 3D Scenes](/tech/xr) are being added to it.

| Year | Forum | Contribution | Record |
| ---- | ----- | ------------ | ------ |
| 2026 | MPEG glTF Validator | Review and comments on the first set of MPEG extensions integrated into the validator (still open) | [Pull request #1](https://github.com/MPEGGroup/glTF-Validator/pull/1) |
