<h1>Content Delivery Protocols</h1>
</div>
</div>

FLUTE and its building blocks are specified by the IETF. 3GPP SA4 profiles FLUTE for MBMS download in TS 26.346 and for the MBS Object Distribution Method in TS 26.517. This page lists the documents and which profile uses which.

The page follows the latest Release 19 issues: TS 26.346 V19.3.0 and TS 26.517 V19.3.0.

:::tip[At a glance]

- **FLUTE version 1:** RFC 3926, with ALC (RFC 3450) and LCT (RFC 3451). Both 3GPP profiles refer to it. FLUTE version 2 (RFC 6726, with RFC 5775 and RFC 5651) is current IETF text, not used by them.
- **FEC schemes:** Compact No-Code (RFC 3695) in every profile; Raptor (RFC 5053) mandatory to support by the UE in MBMS download and in the MBMS Download Profile, which MBS Object Distribution follows.
- **Requirement by requirement:** [FLUTE: what each profile requires](/standards/content-delivery/flute) lists every requirement by feature, with the clause that changes it in each profile and release.
- **3GPP profiles:** MBMS download in TS 26.346 clause 7.2 and annex L.4; MBS Object Distribution in TS 26.517 clause 6.2, which conforms to the MBMS Download Profile.
- **Also tracked:** ROUTE (RFC 9223), not used by either 3GPP profile, and CMMF (ETSI TS 103 973 V1.2.2), which has its own page.

:::

## Which profile uses which

A tick means the profile requires the document, directly or through the profile it builds on.

| Document | Used for | Unprofiled FLUTE | MBMS download | MBS Object Distribution |
| --- | --- | :---: | :---: | :---: |
| RFC 3926 | FLUTE version 1 | ✓ | ✓ | ✓ |
| RFC 3450 | ALC | ✓ | ✓ | ✓ |
| RFC 3451 | LCT | ✓ | ✓ | ✓ |
| RFC 3695 | Compact No-Code FEC (FEC Encoding ID 0) | ✓ | ✓ | ✓ |
| RFC 5053 | Raptor FEC (FEC Encoding ID 1) | — | ✓ | ✓ |
| RFC 1952 | GZip content encoding | — | ✓ | ✓ |
| TS 26.346, clause 7.2 and annex L.4 | FLUTE usage for MBMS download; the MBMS Download Profile | — | ✓ | ✓ |
| TS 26.346, annex L.6 | Profiled FLUTE FDT schema | — | — | ✓ |
| TS 26.517, clause 6.2 | FLUTE for the Object Distribution Method | — | — | ✓ |

- **Unprofiled FLUTE:** RFC 3926 builds on RFC 3450 and RFC 3451, and refers to RFC 3695 for FEC Encoding ID 0. It allows content encoding, GZip among others, without requiring it.
- **MBMS download:** clients and servers implement RFC 3926 with the ALC and LCT features it inherits. Compact No-Code is supported, every UE decodes Raptor, and UEs support GZip decoding.
- **MBS Object Distribution:** the MBS Distribution Session conforms to the MBMS Download Profile, and the MBSTF uses the profiled FDT schema of annex L.6.

What each profile requires, row by row, is in the [Technical Analysis](/tech/content-delivery/features).
