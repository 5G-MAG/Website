This page lists the 3GPP specifications for 5G Multicast Broadcast Services (MBS) in two sections: the MBS User Services, and MBS in the 5G System and NG-RAN. For each document it gives what it covers and its last version in each release.

Versions are read from the 3GPP specification archive on 3 October 2026. Release 20 is still open: its column shows the latest version so far. "none" means the archive holds no version of the document in that release.

:::tip[At a glance]

- **MBS User Services:** TS 26.502 (architecture) and TS 26.517 (protocols and formats), with TS 29.580 and TS 29.581 for the services of the MBSF and the MBSTF. The design in TS 26.502 is primarily motivated by the conclusions of the study TR 26.802.
- **MBS in the 5G System and NG-RAN:** TS 23.247 (stage 2), TS 29.532 (MB-SMF services), TS 29.537 (PCF services), TS 24.575 (UE pre-configuration) and TS 32.279 (charging); MBS parts in six other 5G System specifications; MBS clauses in TS 38.300, TS 38.331, TS 38.413, TS 38.473 and TS 37.483.
- **By release:** Release 17 creates TS 26.502, TS 26.517, TS 29.580, TS 29.581, TS 23.247, TS 29.532 and TS 29.537. Release 18 creates TS 24.575 and TS 32.279. All nine have a Release 19 version; TS 29.580, TS 29.581, TS 23.247, TS 29.532 and TS 29.537 have a Release 20 version.

:::

## MBS

The 5G System and NG-RAN side of MBS, in four groups: specifications whose scope is MBS; 5G System specifications with an MBS part (the clause is named); NG-RAN specifications with clauses for MBS; and the studies. For a specification with an MBS part, the Rel column is the first release whose last version contains that part.
