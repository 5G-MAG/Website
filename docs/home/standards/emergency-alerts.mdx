## Overview

Public warning over 5G Broadcast carries emergency alerts (earthquake and tsunami warnings, and
CMAS-style civil alerts) to any receiver in coverage, using the same free-to-air LTE-based
broadcast carrier as linear TV and radio. Because it needs no SIM, no subscription and no return
channel, it keeps working when the cellular network is congested or unavailable, which is exactly
when warnings matter most.

Three layers define it. **ETSI TS 103 720**, the 5G Broadcast system specification maintained by
5G-MAG, profiles PWS support over the E-UTRAN Uu downlink. **3GPP TS 23.041** defines the Cell
Broadcast Service message itself: its structure, message identifiers, serial numbers and data
coding. **3GPP TS 36.331** defines how that message is encoded on the radio interface, as
SystemInformationBlockType12, and what a UE does on receiving it.

For the release-by-release work-item history behind these specifications, see [Standards Evolution](/standards/emergency-alerts/evolution).

5G-MAG maintains ETSI TS 103 720 and carries the public warning requirements into it, so feedback from implementing the alert chain in the reference tools feeds directly back into the specification. Contributions to this documentation are made through the [5G-MAG Standards repository](https://github.com/5G-MAG/Standards/).

## What the 3GPP specifications state

- **TS 22.268 V21.0.0, clause 1:** "This Technical Specification defines the stage one description of the Public Warning System (PWS) Requirements." Its scope covers ETWS, CMAS, EU-ALERT and KPAS.
- **TS 23.041 V20.0.0, clause 1:** "The present document describes the Cell Broadcast short message service (CBS) for GSM and UMTS." Table 9.4.1.2.2-1 assigns Message Identifier 1102 (hex): "ETWS CBS Message Identifier for earthquake and tsunami combined warning message."
- **TS 29.168 V19.0.0, clause 1:** "The present document specifies the procedures and the SBc Application Part (SBc-AP) messages used on the SBc-AP interface between the Mobility Management Entity (MME) and the Cell Broadcast Centre (CBC), and between the Public Warning System – Inter Working Function (PWS-IWF) and the CBC."
- **TS 36.331 V19.4.0, clause 6.3.1:** "The IE SystemInformationBlockType10 contains an ETWS primary notification." "The IE SystemInformationBlockType11 contains an ETWS secondary notification." "The IE SystemInformationBlockType12 contains a CMAS notification."
- **TR 36.976 V19.0.0, clause 1:** "The present document provides an overview and overall description of the LTE-based 5G terrestrial broadcast comprising:" a free-to-air service and a radio network of MBMS-dedicated or FeMBMS/Unicast-mixed cells.

ETSI TS 103 720, ETSI TS 102 900 and OASIS CAP are not 3GPP documents and are not quoted here.
