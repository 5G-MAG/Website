<h1>UE Data Collection, Reporting and Event Exposure</h1>
</div>
</div>

UE data collection, reporting and event exposure is specified by 3GPP SA4. This page lists its specifications and what each covers.

The page covers Release 17 to Release 19. No Release 20 work item in the 3GPP work plan lists these specifications.

:::tip[At a glance]

- **Specified by:** 3GPP SA4.
- **Two specifications:** TS 26.531 (architecture) and TS 26.532 (protocols and formats).
- **By release:** both are created in Release 17. Release 18 adds immediate data report delivery instructed by the UE application, and ANBR-based network assistance data reporting. Release 19 carries the Release 18 content forward, with an update of the API info and externalDocs fields.
- **Built on:** the 5G System as defined in TS 23.501, TS 23.502, TS 23.288 and TS 29.517, and, for the APIs, TS 29.510.

:::

## Specifications

The Release column is the release of each document's first version. Titles are each document's cover title; the last column summarises its Scope clause.

| Specification | Title | Release | Covers |
| --- | --- | :---: | --- |
| [TS 26.531](https://www.3gpp.org/dynareport/26531.htm) | Data Collection and Reporting; General Description and Architecture | 17 | A generic architecture for collecting and reporting data in the 5G System |
| [TS 26.532](https://www.3gpp.org/dynareport/26532.htm) | Data Collection and Reporting; Protocols and Formats | 17 | The APIs, resource structures and data models for the collection and reporting of UE data by the Data Collection AF, for event exposure to network consumers |

TS 26.531 has the same clause structure in Release 17, 18 and 19. In TS 26.532 the API roots stay at `/v1`; from Release 18 a data reporting configuration is created at `/sessions/{sessionId}/configurations` instead of `/sessions/{sessionId}/configurations/{configurationId}`.
