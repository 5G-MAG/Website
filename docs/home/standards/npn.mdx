## Overview

5G-MAG tracks 3GPP Non-Public Network (NPN) standards for private 5G media production and contribution. For NPN deployment models, identity/onboarding and QoS considerations, see the Technology page linked below. For the release-by-release work-item history behind these specifications, see [Standards Evolution](/standards/npn/evolution).

5G-MAG tracks NPN standardisation as it applies to media production and contribution, in particular the VIAPA requirements, the SNPN and PNI-NPN deployment models, device onboarding at scale, and the combination of NPN with TSC for deterministic essence transport and with RTC for interactive contribution.

## NPN Deployment Models

Both deployment models are defined in clause 5.30 of TS 23.501, Support for non-public networks (SNPN in clause 5.30.2 and PNI-NPN in clause 5.30.3).

- **Standalone NPN (SNPN)**: Independent 5G network with its own core, not relying on a public land mobile network (PLMN). Identified by the combination of a PLMN ID and a Network Identifier (NID).
- **Public Network Integrated NPN (PNI-NPN)**: NPN made available through a PLMN, for example by means of a dedicated Data Network Name (DNN) or one or more network slice instances allocated for the NPN, optionally using a Closed Access Group (CAG) to control which subscribers may access the relevant cells.

## Specifications by release

The NPN feature set has grown across releases. The following is an orientation, not a substitute for the 3GPP work plan.

- **Release 16**: Baseline NPN. Introduced the SNPN and PNI-NPN models, the NID for SNPN, and the CAG mechanism for PNI-NPN (work items Vertical_LAN and, for the RAN, NG_RAN_PRN). Architecture in the NPN clause of TS 23.501.
- **Release 17**: SNPN enhancements (eNPN, NG_RAN_PRN_enh). Credentials Holder support (credentials owned by a separate 3GPP or non-3GPP entity such as an AAA server), UE onboarding and remote provisioning, IMS voice and emergency services and PWS for SNPN. Related VIAPA requirements work continued in TS 22.263.
- **Release 18**: Non-Public Networks Phase 2 (eNPN_Ph2). Mobility between equivalent SNPNs without new network selection, non-3GPP access for SNPN, and access to Localized Services.
- **Release 19**: security for a PLMN hosting an NPN (PLMNNPN, TS 33.501), interconnect of SNPNs (ISN, TS 22.261 and study TR 22.848), ProSe in NPN (TEI19_ProSe_NPN) and CAG-based access control for NR Femto (5G_Femto).
- **Release 20**: security for a PLMN hosting an NPN, phase 2 (PLMNNPN_Ph2-SEC, TS 33.501). No Release 20 description (TR 21.920) exists yet, so confirm Release 20 content against the current 3GPP work plan.

The per-release features and the clauses of TR 21.916 to TR 21.919 that describe them are on [Standards Evolution](/standards/npn/evolution).
