<h1>3GPP RAN and Core Platforms</h1>
</div>
</div>

The 5G Core Service Consumers libraries talk to 5G Core Network Functions through their service-based APIs. This page lists the specifications that define those APIs.

:::tip[At a glance]

- **Four specifications:** TS 29.514 (Policy Authorization, PCF), TS 29.521 (Binding Support Management, BSF), TS 29.532 (MB-SMF services) and TS 29.510 (Network Function Repository, NRF).
- **By release:** TS 29.514, TS 29.521 and TS 29.510 have a first version in Release 15; TS 29.532 in Release 17.
- **Release by release:** the table below lists what each release added to these services, from Release 15 to Release 20.

:::

TS 29.532 has no feature change requests in the Release 19 versions listed in its change history, only API version updates. In Release 20 its change history lists only CR 0099, an API version and external document update (TS 29.532 V20.0.0, CT#112). No work item in the work plan of 28 September 2026 lists TS 29.521 or TS 29.532. The change history does not name the work item of the Release 20 change requests above; the work items are those whose work plan row lists the specification.
