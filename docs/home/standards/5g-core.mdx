<h1>5G Core Service Consumers</h1>
</div>
</div>

The 5G Core Service Consumers libraries talk to 5G Core Network Functions through their service-based APIs. This page lists the specifications that define those APIs.

## Specifications

The Rel column is the release of each document's first version. Titles are each document's cover title.

| Specification | Title | Release | Network Function and service |
| --- | --- | :---: | --- |
| [TS 29.514](https://www.3gpp.org/dynareport/29514.htm) | 5G System; Policy Authorization Service; Stage 3 | 15 | PCF: Npcf_PolicyAuthorization |
| [TS 29.521](https://www.3gpp.org/dynareport/29521.htm) | 5G System; Binding Support Management Service; Stage 3 | 15 | BSF: Nbsf_Management |
| [TS 29.532](https://www.3gpp.org/dynareport/29532.htm) | 5G System; 5G Multicast-Broadcast Session Management Services; Stage 3 | 17 | MB-SMF: Nmbsmf_TMGI and Nmbsmf_MBSSession |
| [TS 29.510](https://www.3gpp.org/dynareport/29510.htm) | 5G System; Network Function Repository Services; Stage 3 | 15 | NRF: discovery of the Network Functions above |
