## Overview

A liaison statement (LS) is a formal message exchanged between standards groups. In the tables below, **Out** means a document that 5G-MAG sent to the body, and **In** means a reply or document that 5G-MAG received. Where a note follows an entry (for example "withdrawn", "approved", "postponed", "revised into ..."), it records the current status of that document or the reply relationship between an outgoing item and the incoming response it triggered.

The tables are grouped by standards body (3GPP, MPEG, ETSI MEC) and listed newest first. Each link downloads the document (a ZIP or office file) from the relevant document server.
