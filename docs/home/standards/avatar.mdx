## Overview

5G-MAG tracks standardisation of avatar communications and the associated immersive voice and audio in 5G systems: the Avatar Representation Format (ARF), an MPEG format for interoperable 3D avatars, MPEG-I Scene Description integration, and Immersive Voice and Audio Services (IVAS), the 3GPP immersive audio codec used alongside them. For the technical analysis of how avatar communication works, see the Tech page linked below. Check the [Standards](https://github.com/5G-MAG/Standards/) repository for the current status of this work as it develops.

## Specifications by role

The standardisation spans MPEG (avatar representation and scene placement) and 3GPP/IETF (real-time transport and immersive audio). The table groups the key specifications by the part of the system they govern; see [Conversational Avatar Communication with MPEG ARF](/tech/avatar) for the technical analysis of how these pieces fit together.

| Role                       | Specifications                                                    |
| -------------------------- | ------------------------------------------------------------------ |
| Avatar representation      | ISO/IEC 23090-39 (ARF)                                             |
| Scene placement            | ISO/IEC 23090-14 and Amendment 2 (MPEG-I Scene Description)        |
| Real-time media transport  | TS 26.114, TS 26.506, draft-ietf-avtcore-rtp-avatar                |
| Immersive audio            | TS 26.250 to TS 26.258 (IVAS)                                      |

## Specifications in scope

The MPEG, 3GPP and IETF deliverables behind avatar communications, filterable by the role they play. Search matches the specification number, its title and any scope note.

ISO/IEC 23090-39 (ARF) defines interoperable storage, carriage and animation of 3D avatars, and is designed to work with MPEG-I Scene Description (ISO/IEC 23090-14; see the [XR page](/standards/xr) for the full Scene Description treatment, including the amendment that adds avatar support). See [Conversational Avatar Communication with MPEG ARF](/tech/avatar) for the ARF data model and end-to-end procedure.

IVAS is the 3GPP immersive voice and audio codec developed by working group SA4. Its deliverables span the general overview, the fixed- and floating-point C code, test material, the detailed algorithmic description (including the RTP payload format and SDP parameters used to negotiate the codec in a session), rendering, error concealment, and jitter buffer management.
