<h1>CMMF (Multisource Delivery)</h1>
</div>
</div>

ETSI TS 103 973 defines the Coded Multisource Media Format (CMMF), a container format for carrying coded media from more than one network source at once. See [CMMF in the Technical Analysis](/tech/content-delivery/more/cmmf) for how it works.

3GPP SA4 references CMMF as part of the Release 19 Advanced Media Delivery study (TR 26.804); the Release 19 description of Advanced Media Delivery also lists CMMF among its stage 3 items, for media delivery from multiple service endpoints (TR 21.919 clause 11.6); see [Media Streaming and Advanced Media Delivery: Specifications](/standards/5gms) and [Advanced Media Delivery](/tech/5gms/more/advanced-media-delivery) for that context. 5G-MAG tracks CMMF itself as a repository of [Content Delivery Protocols and Tools](/tech/content-delivery), alongside FLUTE and ROUTE, rather than as a separate project.

:::tip[At a glance]

- **Specification:** ETSI TS 103 973, the Coded Multisource Media Format (CMMF), at V1.2.2 (May 2026).
- **In 3GPP:** SA4 references CMMF in the Release 19 Advanced Media Delivery study (TR 26.804) and in its stage 3 items (TR 21.919 clause 11.6).
- **In 5G-MAG:** CMMF is tracked as a repository of Content Delivery Protocols and Tools, not as a separate project.

:::
