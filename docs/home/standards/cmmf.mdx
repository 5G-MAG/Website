<h1>CMMF (Multisource Delivery)</h1>
</div>
</div>

ETSI TS 103 973 defines the Coded Multisource Media Format (CMMF), a container format for carrying coded media from more than one network source at once. See [CMMF in the Technology](/tech/content-delivery/cmmf) for how it works.

3GPP SA4 describes media delivery using CMMF in TR 26.804 V19.1.0 (Study on 5G media streaming extensions), clause 5.19.1.7; the Release 19 description of Advanced Media Delivery also lists CMMF among its stage 3 items, for media delivery from multiple service endpoints (TR 21.919 clause 11.6); see [Media Streaming and Advanced Media Delivery: Specifications](/standards/5gms) and [Advanced Media Delivery](/tech/5gms/advanced-media-delivery) for that context. 5G-MAG tracks CMMF itself as a repository of [Content Delivery Protocols and Tools](/tech/content-delivery), alongside FLUTE and ROUTE, rather than as a separate project.

:::tip[At a glance]

- **Specification:** ETSI TS 103 973, the Coded Multisource Media Format (CMMF), at V1.2.2 (May 2026).
- **In 3GPP:** SA4 describes media delivery using CMMF in TR 26.804 V19.1.0, clause 5.19.1.7, and TR 21.919 V19.0.0 clause 11.6 lists CMMF among the stage 3 items.
- **In 5G-MAG:** CMMF is one of the technologies of Content Delivery Protocols and Tools, with the CMMF Encoder (rt-cmmf-encoder) as its repository.

:::
