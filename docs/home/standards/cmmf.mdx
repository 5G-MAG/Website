## Overview

ETSI TS 103 973 defines the Coded Multisource Media Format (CMMF), a container format for carrying coded media from more than one network source at once. See [CMMF in the Technical Analysis](/tech/content-delivery/cmmf) for how it works.

3GPP SA4 references CMMF as part of the Release 19 Advanced Media Delivery study (TR 26.804); see [Standards: 5G Media Streaming (5GMS)](/standards/5gms) and [Advanced Media Delivery](/tech/5gms/overview-amd) for that context. 5G-MAG tracks CMMF itself as a repository of [Content Delivery Protocols](/tech/content-delivery), alongside FLUTE and ROUTE, rather than as a separate project. For the version history behind this specification, see [Standards Evolution](/standards/cmmf/evolution).
