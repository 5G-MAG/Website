<h1>UE Data Collection, Reporting and Event Exposure - Standards Evolution</h1>
</div>
</div>

:::tip[At a glance]

- **Release 17:** the EVEX work item creates TS 26.531 and TS 26.532.
- **Release 18:** change requests under EVEX, TEI18 and 5GMS_Pro_Ph2.
- **Release 19:** the Release 18 content carried forward; TS 26.532 V19.1.0 updates the API info and externalDocs fields.

:::

Work items as listed in the 3GPP work plan of 28 September 2026. Change requests as listed in the change history of TS 26.531 V19.0.0 and TS 26.532 V19.1.0.
