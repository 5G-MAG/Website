5G Media Streaming (5GMS) is specified by 3GPP SA4. This page lists its specifications and what each covers.

The page covers Release 16 to Release 19. Release 20 work is in progress.

:::tip[At a glance]

- **Specified by:** 3GPP SA4.
- **Ten documents:** seven specifications (TS 26.501, TS 26.510, TS 26.511, TS 26.512, TS 26.117, TS 26.531, TS 26.532) and three reports (TR 26.804, TR 26.802, TR 26.941).
- **By release:** Release 16 creates TS 26.501, TS 26.511, TS 26.512 and TS 26.117; Release 17 adds TS 26.531, TS 26.532, TR 26.804 and TR 26.802; Release 18 creates TS 26.510 and publishes TR 26.941; Release 19 brings Advanced Media Delivery and a TS 26.511 update for MV-HEVC.

:::

## Specifications from other bodies

5GMS reuses formats and protocols from other bodies. A tick means that TS 26.501, TS 26.511 or TS 26.512 references the document in that release.

| Specification | Used for | Up to Release 16 | Up to Release 17 | Up to Release 18 | Up to Release 19 |
| --- | --- | :---: | :---: | :---: | :---: |
| ISO/IEC 23000-19, CMAF | Common media segments for DASH and HLS | ✓ | ✓ | ✓ | ✓ |
| ISO/IEC 23009-1, MPEG-DASH | Media presentation and segment formats | ✓ | ✓ | ✓ | ✓ |
| CTA-5003, device playback capabilities | Device capability profiles | ✓ | ✓ | ✓ | ✓ |
| CTA-5005, DASH-HLS interoperability | One set of segments for both player types | — | — | ✓ | ✓ |
| CTA-5004, Common Media Client Data (CMCD) | Client data reporting | — | — | ✓ | ✓ |
| ETSI TS 103 998, Content Steering for DASH | Steering clients across CDNs | — | — | — | ✓ |
| ETSI TS 103 973, CMMF | Delivery from multiple sources | — | — | — | ✓ |
| ETSI TS 103 799, CPIX | Content protection key exchange | — | — | — | ✓ |

Common Media Server Data (CTA-5006) is studied in TR 26.804 but not yet referenced by a 5GMS specification.
