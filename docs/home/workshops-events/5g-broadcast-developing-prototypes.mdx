The 5G Media Action Group (5G-MAG) organized the workshop "5G Broadcast: Developing Prototypes". This interactive workshop brought together developers working on the implementation of 5G Broadcast prototypes, with an approach covering service provisioning, core network and RAN implementations, as well as receiver and applications.

## Agenda

1. Tour the table
2. SW development and collaboration &mdash; experience from DASH-IF
3. Network and radio aspects
   - Open Air Interface
   - OBECA project and SRS-LTE
   - TU-BS platform
4. Virtualization
   - OAI MANO vRAN/OSM/Kubernetes
5. Applications and media-related aspects
   - DASH/CMAF/ffmpeg
6. Discussion, collaboration and way forward

More information was available via [gimenez@5g-mag.com](mailto:gimenez@5g-mag.com).

This workshop was organized under 5G-MAG's Developer Xchange work.
