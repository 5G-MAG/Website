## What it does

<ProjectSlide image="/assets/images/projects/beyond-2d-testbed.png" alt="Beyond 2D Evaluation Framework: Testbed slide">

The framework enables standardised benchmarking of encoding, streaming, and rendering pipelines for content that goes beyond traditional flat-screen delivery, feeding directly into 3GPP and MPEG standardisation of new immersive video formats.

</ProjectSlide>

See [Beyond 2D on the Standards portal](/standards/beyond-2d) for related work items and specs.
