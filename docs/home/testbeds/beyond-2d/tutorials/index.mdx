## [Run a multi-view plus depth evaluation](./mvd-first-evaluation)

Build TMIV and QMIV, put the test content in place, run a small evaluation of one coding condition and read the output files.

## [Compare coding conditions](./mvd-compare-conditions)

Run the three coding conditions at four rate points, collect the bitrate and the objective quality in one table and compare them.

## [Prepare, encode and measure V-PCC point clouds](./vpcc-point-clouds)

Make point clouds from a mesh sequence, encode and decode them with V-PCC, read the metrics and render videos along a camera path.

For what the framework evaluates and the specifications it tracks, see the [Implementation Detail](../implementation) page. For the repositories and their READMEs, see [Repositories & Releases](/testbeds/beyond-2d#repositories--releases).
