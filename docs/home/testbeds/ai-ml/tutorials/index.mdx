## [Set up and run a first evaluation](./first-evaluation)

Install the framework, evaluate the wav2vec 2.0 model for speech recognition with no compression and with NNCodec, and read the result file.

## [Sweep quantization parameters and plot the trade-off](./qp-sweep)

Run the NNCodec evaluation over a range of quantization parameters, plot word error rate against compressed size, and read the plot against the test cases of TR 26.847.

## [Add a compression method](./add-compression-method)

Write a new coder, register it in the pipeline and compare it with the anchor and with NNCodec.

## Network emulation and traffic characterisation

The framework in this repository does not emulate a network. For that, use the [6G AI Traffic Characterization Testbed tutorials](/testbeds/6g-testbed/tutorials).
