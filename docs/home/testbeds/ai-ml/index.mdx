## What it does

The repository README describes the purpose as to "establish an evaluation framework and use it for the evaluation of scenarios collected for the FS_AI4Media study", with "common testbed architectures and anchors, metrics (e.g. AI/ML task metrics, feasibility/performance metrics), and specific details (such as test configuration and constraints) for each scenario evaluation". 3GPP TR 26.847 V19.0.0 clause 4.1 states: "A common set of architectures is assumed for the evaluation framework, unless specified otherwise, irrespective of the scenario." Its reference [16] is this repository ("5G-MAG repository for AI4Media evaluations").

3GPP [TR 26.927](https://www.3gpp.org/dynareport/26927.htm) (Study on Artificial Intelligence and Machine Learning in 5G media services) and its companion evaluation report [TR 26.847](https://www.3gpp.org/dynareport/26847.htm), both Release 19, plus [TR 22.874](https://www.3gpp.org/dynareport/22874.htm) (Study on traffic characteristics and performance requirements for AI/ML model transfer in 5GS).
