## About the Workshop

A new set of 5G standards under the name "5G Advanced" was on the horizon. This interactive workshop brought 5G-MAG members together to discuss potential new areas of work and/or enhancements to the 5G specifications for media distribution in 3GPP Release 18.

The detailed agenda was to be communicated closer to the event date.
