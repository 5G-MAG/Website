## Agenda — 5G Media Use Cases and Applications

Call 3 continued from where Call 2 left off: the remaining hybrid broadcast/multicast/unicast use cases, followed by use cases related to eXtended Reality.

Participants who had already registered for Call 1 or Call 2 did not need to register again, as the same Zoom link was reused across the series. Anyone joining for the first time needed to register.

The use-case submission window remained open throughout, with 5G-MAG inviting the community to send in further use cases for discussion.

Call 4 (limited to 5G-MAG members) and Call 5 were announced as following shortly after in the same series.
