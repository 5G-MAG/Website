## About Call 2

Call 1 gave participants an overview of the 5G Media specifications, including 5G Media Streaming, dynamic network QoS policies, media streaming over eMBMS, edge applications for streaming, 5G Multicast Broadcast Services, the event exposure framework, and eXtended Reality.

Call 2 moved from overview to application: participants were invited to think through and develop the use cases that would drive the development of the 5G-MAG Reference Tools for 2023.

## Whether you were interested in...

- 5G Media in connected cars
- 5G Media in smartphones
- 5G Media in smart glasses
- 5G Media for smart TVs
- 5G Media and the edge
- 5G Media for OTT players
- 5G Media for television
- 5G Media for immersive
- 5G Media for radio
- 5G Media for speakers
- 5G Media for the metaverse
- 5G Media for &hellip;?

...the call was open for anyone to present and discuss their own use case. Those who had already registered for Call 1 used the same Zoom link and did not need to register again; others could [register for Call 2](https://us06web.zoom.us/meeting/register/tZcldO2orD4vHtWrYnWKiCbRZ3leYhiecz3Q).

## Use case submissions

The submission window was open for use cases and supporting files:

- [Submit a use case](https://docs.google.com/forms/d/e/1FAIpQLScJUgmxaVWnEgoAfXYkAySIhEo3jpWj0p_nv0NotGGjvWYUZA/viewform)
- [Upload a supporting file](https://docs.google.com/forms/d/e/1FAIpQLSdq8VWTLFYVJ4DYF_1arlbBu1OwrjPEw9bq-ADznvWqKvZQEg/viewform), or send it by email to [reference-tools@5g-mag.com](mailto:reference-tools@5g-mag.com)

Call 3 in the series followed by the end of July 2022; participants who had attended a previous call did not need to register again.
