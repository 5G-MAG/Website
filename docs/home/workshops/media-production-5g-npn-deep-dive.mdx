## About the Workshop

The 5G Media Action Group (5G-MAG) organized the workshop "Media Production and 5G Non-Public Networks: Deep dive into media production protocols". The interactive session gathered input from stakeholders across the media and ICT industries around the work in the related [3GPP study](https://www.5g-mag.com/post/new-3gpp-study-on-media-production-over-5g-npn), focusing on how the diverse set of media production and transport protocols may need to interface with, and be supported by, the 5G System.

## Presentations

- **Welcome** — Ian Wagdin (CP-C Chair, BBC)
- **The technical activities in 5G-MAG** — Thibaud Biatek (CP-T Chair, ATEME)
- **Technical Report on Media Production and 5G NPNs** — Thorsten Lohmar (3GPP SA4 Study Item NPN4AVPROD Rapporteur, Ericsson)
- **QoS and Prioritization** — David Butler, Ivan Hassan (BBC)

## Homework

Attendees were invited to contribute input on aspects of workflows supporting wireless connectivity via a short questionnaire circulated ahead of the session.
