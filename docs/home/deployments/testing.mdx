</div>

How do you know that an implementation works, and that it works with others? This page gathers what 5G-MAG offers for that: PlugFests, conformance validators and the implementation status of each Reference Tool.

## PlugFests

At a PlugFest, implementations are tested side by side. The latest was the **5G Broadcast PlugFest 2026**, 9 to 11 June 2026, hosted by Fraunhofer FOKUS in Berlin. It tested interoperability against ETSI TS 103 720, including transmitter and core network interoperability, single-frequency network configurations, service provisioning and streaming, and integration with DVB-I services.

- [5G Broadcast PlugFest 2026](/deployments/5g-broadcast-plugfest): the scope of the event.
- [PlugFest recap](/news/plugfest-berlin-2026): results, participants and outcomes.
- [Events](/events): what is coming next.

## Conformance and validation tools

These tools check an implementation against a specification.

- **[VOPS Conformance Validator](/validation/vops):** validates video bitstreams against the operation points of 3GPP TS 26.265.
- **FLUTE Conformance Validator**, part of [Content Delivery Protocols](/reference-tools/content-delivery): tests a FLUTE implementation against the FLUTE profiles of RFC 3926, 3GPP TS 26.346 and 3GPP TS 26.517.

## Implementation status

For some Reference Tools, the code on the main branch has been read against the specifications, and the result is published as the implementation status. The [Reference Tools](/reference-tools) page shows which projects have one, with the Release it covers; the others are marked as coming soon.

- [5G Media Streaming](/reference-tools/5gms/implementation)
- [5G Multicast Broadcast Services](/reference-tools/5g-mbs/implementation)
- [Content Delivery Protocols](/reference-tools/content-delivery/implementation)
- [UE Data Collection, Reporting and Event Exposure](/reference-tools/data-collection/implementation)
- [DVB-I Services over 5G Systems](/reference-tools/dvb-i/implementation)
