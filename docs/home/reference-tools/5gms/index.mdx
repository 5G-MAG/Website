<ProjectSlide image="/assets/images/projects/5gms-reference-tools.png" alt="5G Media Streaming (5GMS): Reference Tools slide">

The tools cover two server-side roles: the Application Function (AF), which handles provisioning, configuration and reporting, and the Application Server (AS), which caches and delivers the media. Both target 5G Unicast Downlink Media Streaming (5GMSd), against the Release 17 normative baseline ([TS 26.501](https://www.3gpp.org/dynareport/26501.htm) / [TS 26.512](https://www.3gpp.org/dynareport/26512.htm)). For the deployment configurations and full specification detail, see [Implementation Detail](./implementation).

</ProjectSlide>

**Implemented specifications:** 3GPP [TS 26.501](https://www.3gpp.org/dynareport/26501.htm) (5G Media Streaming general description and architecture), [TS 26.512](https://www.3gpp.org/dynareport/26512.htm) (5G Media Streaming protocols), against the Release 17 normative baseline. See [Implementation Detail](./implementation) for the full specification list (TS 26.501, TS 26.510, TS 26.511, TS 26.512) and Release-19 tracking.

See [5G Media Streaming (5GMS) on the Standards portal](/standards/5gms) for version history and 5G-MAG's own standards contributions.
