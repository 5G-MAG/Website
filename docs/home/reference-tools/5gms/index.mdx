<h1>Media Streaming and Advanced Media Delivery</h1>

The tools cover two server-side roles: the Application Function (AF), which handles provisioning, configuration and reporting, and the Application Server (AS), which caches and delivers the media. Both target 5G Unicast Downlink Media Streaming (5GMSd), against the Release 17 normative baseline ([TS 26.501](https://www.3gpp.org/dynareport/26501.htm) / [TS 26.512](https://www.3gpp.org/dynareport/26512.htm)). For the deployment configurations and full specification detail, see [Implementation status](./implementation).
