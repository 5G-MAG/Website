:::tip[In short]

- **What is covered:** the 5GMS Application Function, Application Server, Media Session Handler, Media Stream Handler, common Android library, 5GMS-Aware Application and Application Provider.
- **Which release:** the code is built against the Release 17 APIs (TS 26.512 V17.10.0). The view below opens at Release 20, so many cases read as not implemented because the code predates that release. Filter by release to judge it against the release it targets.
- **Source of this page:** an audit of the `main` branch of each repository on 2026-10-10, at the released version listed for each component: each requirement split into the cases its clause defines, each case read against the code by one reader and then independently by a second, with a third reading where they disagreed. Cases that reading the code cannot settle are not shown.

:::

For what the specifications define, see the [Technology page](/tech/5gms/overview). For how to run the tools, see the [Tutorials](/reference-tools/5gms/tutorials).
