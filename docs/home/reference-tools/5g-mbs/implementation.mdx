:::tip[In short]

- **MBS User Services** (MBSF, MBSTF, MBS Client, MBS-Aware Application, Application Provider): audited against the Release 17 to 20 specifications (the view opens at Release 20). The code is built against the Release 18 interfaces.
- **MBS in the 5G System and NG-RAN:** not yet audited.
- **Source of this page:** an audit of the `main` branch of each repository on 2026-10-11: each requirement split into the cases its clause defines, each case read against the code by one reader and then independently by a second, with a third reading where they disagreed. Cases that reading the code cannot settle are not shown.

:::

For what the specifications define, see the [Technology](/tech/5g-mbs). For how to run the tools, see the [Tutorials](/reference-tools/5g-mbs/tutorials).

## Used with other projects

- **FLUTE** (rt-libflute): the MBSTF and the MBS Client use it for object delivery. See [Content Delivery Protocols and Tools](/reference-tools/content-delivery/implementation).
- **5GC Service Consumers** (rt-5gc-service-consumers): the MBSF reaches the MB-SMF through its MB-SMF library. See [3GPP RAN and Core Platforms](/reference-tools/3gpp-platforms/implementation).
