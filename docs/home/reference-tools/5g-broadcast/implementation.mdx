<h1>Implementation Detail</h1>

:::tip[In short]

- **What the tools are:** a transmitter (rt-mbms-tx) and a receiver (rt-mbms-modem) for LTE-based 5G Broadcast, with a transmitter variant for Qualcomm reference devices.
- **Status:** not yet audited. The statements below come from the repository READMEs.
- **Source of this page:** the READMEs of the `main` branch of the repositories; no code audit has been done yet.

:::

For what the specifications define, see the [Technology](/tech/5g-broadcast) and the [Standards](/standards/5g-broadcast). For how to run the tools, see the [Tutorials](./tutorials) and the [Developer Exchange](./tutorials#developer-exchange).

## Implementation status

Not yet audited. The status of each repository, from its README:

- **rt-mbms-tx:** a standalone LTE-based 5G Broadcast transmitter, based on the srsRAN 4G eNodeB and modified to include a feature set of 3GPP Release 17. Control plane data comes from configuration files (there is no M2 interface) and a single MCH can be transmitted.
- **rt-mbms-modem:** converts a 5G Broadcast signal, received as I/Q samples from a software defined radio or from a recorded file, into multicast IP packets.
- **rt-mbms-tx-for-qrd-and-crd:** an extension of an MBMS-enabled eNodeB that operates as a 5G Broadcast transmitter for Qualcomm Reference Design (QRD) devices; it does not need uplink connectivity from the receiving devices.

Support for the features of later releases is not yet audited.
