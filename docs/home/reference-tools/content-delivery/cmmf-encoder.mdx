## What it is

The CMMF Encoder encodes packaged media into Coded Multisource Media Format (CMMF) bitstreams for multisource delivery. CMMF is a container format for carrying coded media from more than one source. It supplements existing packaging, such as ISO BMFF or CMAF, rather than replacing it, and it carries no manifest of its own. The repository is the encoder side only: source data in, CMMF bitstreams out. The decoder and the delivery architecture are out of scope.

Its README marks it as experimental and says that the repository is at its initial commit, so no encoder code has landed yet. The status is on the [Implementation Detail](./implementation#cmmf-encoder) page.

## Specification basis

ETSI TS 103 973 V1.2.2 (2026-05), Coded Multisource Media Format (CMMF) for Content Distribution and Delivery. The README names code type xCD-1, which the specification defines in its annex A. For the specification, see [CMMF on the Standards portal](/standards/cmmf).
