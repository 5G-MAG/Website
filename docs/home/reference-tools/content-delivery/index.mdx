<h1>Content Delivery Protocols and Tools</h1>
</div>
</div>

Content Delivery Protocols and Tools are the Reference Tools for the application layer of delivery: how media is encoded, packaged, served, carried over 5G and received. This page lists each tool, the specification behind it and where it is used, and each tool has its own page. FLUTE (file delivery, in rt-libflute) is implemented here; ROUTE (real-time object delivery) is implemented in the MBMS Client of [5G Broadcast](/reference-tools/5g-broadcast) (repository rt-mbms-client), and this project is used with it. Useful for developers validating DASH/HLS players, packagers and Content Delivery Network (CDN) integrations in 5G environments. For the status of each tool, see [Implementation Detail](./implementation).

## Standards implemented

<div class="standard-card">

**Implemented specifications:** IETF RFC 3926/RFC 6726 (FLUTE) in rt-libflute. ETSI TS 103 973 (CMMF) is the basis of the CMMF Encoder. DASH (ISO/IEC 23009-1), HLS (RFC 8216) and CMAF (ISO/IEC 23000-19) are the formats the media origin packages and these transports carry, not specifications the tools implement themselves. ROUTE (IETF RFC 9223) is implemented in the MBMS Client of [5G Broadcast](/reference-tools/5g-broadcast).

See [Content Delivery Protocols and Tools on the Standards portal](/standards/content-delivery) for the full specification list.
