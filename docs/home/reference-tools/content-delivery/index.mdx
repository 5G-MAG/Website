<h1>Content Delivery Protocols</h1>
</div>
</div>

These tools address the application-layer delivery protocols that sit above the 5G transport, ensuring interoperability across content formats, packaging standards, and player implementations. The project is designed to support any delivery protocol; it currently implements FLUTE and ROUTE, used respectively for file and real-time object delivery over 5G Broadcast and 5G Multicast Broadcast Services (MBS). Useful for developers validating DASH/HLS players, packagers, and Content Delivery Network (CDN) integrations in 5G environments. For the architectures these transports plug into and the per-feature FLUTE audit, see [Implementation Detail](./implementation).

## Standards implemented

<div class="standard-card-row">
<div class="standard-card">
<img src={useBaseUrl('/assets/logos/IETF.png')} alt="IETF" />
<span class="standard-card__label">RFC 3926 (FLUTE)</span>
</div>
<div class="standard-card">
<img src={useBaseUrl('/assets/logos/IETF.png')} alt="IETF" />
<span class="standard-card__label">RFC 9223 (ROUTE)</span>
</div>
</div>

**Implemented specifications:** IETF RFC 3926/RFC 6726 (FLUTE) and RFC 9223 (ROUTE) — the transports the tools implement. DASH (ISO/IEC 23009-1), HLS (RFC 8216) and CMAF (ISO/IEC 23000-19) are the formats these transports carry as opaque segments and manifests, not something the tools implement themselves.

See [Content Delivery Protocols on the Standards portal](/standards/content-delivery) for the full specification list.
