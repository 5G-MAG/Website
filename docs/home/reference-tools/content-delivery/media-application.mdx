**Role in the chain:** Receive and test. Repository: [rt-media-android-application](/reference-tools/content-delivery#repo-rt-media-android-application) (its card on the project page, with links to GitHub).

## What it is

The Reference Media Application is an Android app with a laptop test rig. In Watch mode it shows the channels of a [Media Origin](./media-origin) as rows of posters and plays them. In Test mode it builds one test per delivery method the origin is configured to send, plays each on the phone, and writes a JSON report of what arrived against what the configuration declares. The status is on the [Implementation Detail](./implementation#media-application) page.

## Specification basis

The application implements no specification of its own. It checks that what the media origin is configured to send arrives and plays, and it plays with AndroidX Media3. The delivery methods and the documents behind them are those of the [Media Origin](./media-origin).

## Where it is used

It is the receiving side of the [Media Origin](./media-origin). No other project documents its use of it.
