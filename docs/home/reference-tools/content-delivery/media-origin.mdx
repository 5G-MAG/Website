**Role in the chain:** Package and serve. Repository: [rt-media-origin](/reference-tools/content-delivery#repo-rt-media-origin) (its card on the project page, with links to GitHub).

## What it is

The Media Origin is a config-driven origin for 5G-MAG demos. One configuration file and one process package each channel with ffmpeg as DASH, HLS or CMAF, and deliver it over HTTP or a push transport (SRT, RIST, RTMP, RTSP, RTP or MoQ). A browser dashboard edits the configuration and starts and stops the channels, and a Docker image runs the origin on any machine.

Sending over FLUTE is out of scope for the origin: according to its README, a FLUTE sender reads the packaged output folder. The status is on the [Implementation Detail](./implementation#media-origin) page.

The repository is private; see [Early Access](/early-access).

## Specification basis

The origin implements no specification of its own. It packages with ffmpeg, and the manifest checks in its repository cite RFC 8216 (HTTP Live Streaming), ISO/IEC 23009-1 (DASH), ISO/IEC 23000-19 (CMAF), ETSI TS 103 285 and RFC 6381 (codec strings). The README does not pin the editions, and the checks test signalling and structure, not bitstreams.

## Where it is used

[5G Media Streaming (5GMS)](/reference-tools/5gms), [5G Multicast Broadcast Services (MBS)](/reference-tools/5g-mbs) and [MPEG V3C Immersive Platform](/reference-tools/v3c) list this repository among the repositories they cross-reference. The [Reference Media Application](./media-application) plays and tests what it sends.
