- **Status:** not yet audited. The audit of the FLUTE library will be done on the `main` branch of the repository; this page shows the state described by each repository's README until then.
- **FLUTE library (rt-libflute):** a library for sending and receiving files with FLUTE, used by the 5G Multicast Broadcast Services and 5G Broadcast Reference Tools.

For what the specifications define, see the [Standards page](/standards/content-delivery/flute) and the [Technology](/tech/content-delivery/features). For how to run the tools, see the [Tutorials](/reference-tools/content-delivery/tutorials).

## Implementation status

Not yet audited.

- **rt-libflute:** a FLUTE library, marked "Under Development" in its README.
- **rt-media-origin:** a config-driven media origin that packages content with ffmpeg as DASH, HLS or CMAF and delivers it over HTTP or real-time push protocols, with FLUTE metadata for multicast. Its README marks it as working.
- **rt-media-android-application:** an Android test app and a laptop test rig that check that each delivery method of the media origin arrives on a phone, plays, and matches the origin's configuration.
- **rt-cmmf-encoder:** encodes packaged media into Coded Multisource Media Format bitstreams for multisource delivery, per ETSI TS 103 973. Its README marks it as experimental.

## Used with other projects

- **5G Multicast Broadcast Services:** the MBS Transport Function sends and the MBS Client receives with rt-libflute. See [5G MBS](/reference-tools/5g-mbs/implementation).
- **5G Broadcast:** the BM-SC sends and the MBMS Client receives with rt-libflute.
