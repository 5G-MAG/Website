**Role in the chain:** Deliver. Repository: [rt-libflute](/reference-tools/content-delivery#repo-rt-libflute) (its entry on the project page, with links to GitHub).

## What it is

The FLUTE Library is an implementation of a FLUTE server and client. It comes with two demo applications, a receiver and a transmitter, and its README describes optional IPSec protection of the transmission and a test suite. Its README marks it as under development. The status, feature by feature, is on the [Implementation status](./implementation#libflute) page.

## Specification basis

FLUTE (File Delivery over Unidirectional Transport), IETF RFC 3926, as profiled by 3GPP TS 26.346 (MBMS) and TS 26.517 (MBS). See [FLUTE requirements by profile](/standards/content-delivery/flute). The [FLUTE Conformance Validator](/validation/flute) tests the library against these profiles.

## Where it is used

[5G Multicast Broadcast Services (MBS)](/reference-tools/5g-mbs) (the MBS Transport Function sends and the MBS Client receives with it) and [5G Broadcast](/reference-tools/5g-broadcast) (the BM-SC sends and the MBMS Client receives with it).
