The tools enable delivery of dynamic 3D scenes composed of glTF (GL Transmission Format) objects, spatial audio, and haptic elements, transported via the 5G Media Streaming (5GMS) framework ([TS 26.512](https://www.3gpp.org/dynareport/26512.htm)). Designed for developers exploring immersive media delivery and XR experiences on 5G devices and platforms. For the full glTF extension support matrices and how the tools map to the standard, see [Implementation Detail](./implementation); to see one assembled scenario already running, see the [Tutorials](./tutorials).

</ProjectSlide>

## Standards implemented

<div class="standard-card-row">
<div class="standard-card">
<img src={useBaseUrl('/assets/logos/MPEG.png')} alt="MPEG" />
<span class="standard-card__label">ISO/IEC 23090-14</span>
</div>
</div>

ISO/IEC 23090-14 (MPEG-I Scene Description, the format that describes how 3D objects, media and audio are composed into a scene), plus the MPEG glTF 2.0 extensions listed on [Implementation Detail](./implementation). 3GPP [TR 26.928](https://www.3gpp.org/dynareport/26928.htm) (Extended Reality (XR) in 5G) is the background study of use cases and requirements this work responds to, not a specification the tools implement; TS 26.512 (5GMS transport) is explicitly out of scope today (see [Implementation Detail](./implementation) for the detail).

See [XR on the Standards portal](/standards/xr) for version history and 5G-MAG's own standards contributions.
