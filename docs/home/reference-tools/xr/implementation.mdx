<h1>Implementation Detail</h1>
</div>
</div>


:::tip[In short]

- **What is checked:** the XR player (Presentation Engine), the Media Access Function and the reference scene files, against ISO/IEC 23090-14 (second edition) and the XR clauses of TS 26.119, TS 26.143 and TS 26.565.
- **What works:** loading and playing media through circular buffers, timed accessors, video textures, part of the spatial audio, and the larger part of AR anchoring and interactivity.
- **What is partial or missing:** several anchoring and interactivity behaviours differ from the specification; scene updates, mesh linking, recommended viewports, animation timing, lighting, avatars and haptics are not used by the reference scenes or are not handled by the player. Many extensions are not used by the reference scenes; those are shown as absent, which means not in the repositories, not a defect.
- **Source of this page:** an audit of the `main` branch of the XR repositories on 2026-10-11, each case read against the code by one reader and then independently by a second, with a third reading where they disagreed; nothing was run. Cases that could not be settled by reading the code are not shown.

:::

For what the specifications define, see the [Technical Analysis](/tech/xr) and the [Standards](/standards/xr). For how to run the tools, see the [Tutorials](/reference-tools/xr/tutorials).
