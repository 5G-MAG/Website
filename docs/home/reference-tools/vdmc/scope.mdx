## What This Project Implements

A web-based decoder and player for Dynamic Mesh Coding (V-DMC) content, defined in ISO/IEC 23090-29 — a standard for compressing 3D meshes whose geometry, connectivity and attributes change per frame. See [Tech: Dynamic Mesh Coding](/tech/vdmc) for what the standard itself covers.

**This page is a starting placeholder.** The reference tool is in early development; a detailed coverage table (which V-DMC profiles/features the decoder supports) will be added here as that work progresses.
