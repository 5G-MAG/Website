<ProjectSlide image="/assets/images/projects/data-collection-reference-tools.png" alt="UE Data Collection, Reporting and Event Exposure: Reference Tools slide">
The tools provide the Data Collection AF: a library and a standalone Application Function that serve provisioning (R1), data reporting (R2 to R4) and event exposure (R5, R6), against Release 18 ([TS 26.531](https://www.3gpp.org/dynareport/26531.htm), [TS 26.532](https://www.3gpp.org/dynareport/26532.htm)). Its integration with 5G Media Streaming is in progress. For each feature and component, see [Implementation Detail](./implementation).
</ProjectSlide>

**Implemented specifications:** 3GPP [TS 26.531](https://www.3gpp.org/dynareport/26531.htm) (data collection and reporting architecture) and [TS 26.532](https://www.3gpp.org/dynareport/26532.htm) (protocols and formats), Release 18, with event exposure from [TS 29.517](https://www.3gpp.org/dynareport/29517.htm). See [Implementation Detail](./implementation) for what each component implements.

See [UE Data Collection on the Standards portal](/standards/data-collection) for the specifications and their evolution.
