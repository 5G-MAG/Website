:::tip[In short]

- **Which specification the code follows:** Release 18, TS 26.532 V18.3.0 and TS 29.517 V18.6.0, as the Data Collection AF build pins. Release 19 adds nothing to implement.
- **Generic framework:** a Data Collection AF library and a standalone AF serve R1, R2 to R4, R5 and R6. No data collection client is provided.
- **In 5G Media Streaming:** the 5GMS components do not yet use the Data Collection AF; the integration is in progress.
- **Source of this page:** a code audit of the repositories on 2026-10-01.

:::

For what the specifications define, see the [Technical Analysis](/tech/data-collection/overview). For how to run the tools, see the [Application Showcase](/reference-tools/data-collection/tutorials).

## Components

### Data Collection AF

<RepoCards slugs={['rt-data-collection-application-function']} />

- **Built against:** TS 26.532 V18.3.0 and TS 29.517 V18.6.0 (Release 18).
- **Implemented:** creating, reading and deleting Provisioning Sessions, Data Reporting Configurations and Data Reporting Sessions; communication reports; time-window aggregation; event subscription and notification at R5 and R6; registration of one AF profile with the NRF.
- **Needs fix:** replacing a Data Reporting Configuration does not store it; the aggregation names MAXIMUM and MINIMUM are not accepted; `"expedite": false` is treated as true; replacing a subscription does not change its notifications; the installed default configuration uses section names the library does not read, so the AF starts without its data collection servers.
- **Not implemented:** PATCH, user and location restrictions, record types other than communication, TLS and OAuth 2.0, and a Direct, Indirect or AS data collection client.

### 5G Media Streaming components

<RepoCards slugs={['rt-5gms-application-function', 'rt-5gms-application-server', 'rt-5gms-media-session-handler', 'rt-5gms-application-provider']} />

- **5GMS AF:** no Data Collection AF and no Event Data Processing provisioning yet; QoE metrics and consumption reports received at M5 are written to files. Work to embed the Data Collection AF library in the 5GMS AF is in progress and not yet usable.
- **5GMS AS:** no reporting of media streaming access activity at R4.
- **5GMS client:** the Media Session Handler sends QoE metrics and consumption reports at M5. ANBR-based Network Assistance reporting at R2 is a Release 18 addition, beyond the Release 17 the 5GMS AF is built against.
- **5GMS Application Provider:** the M1 Event Data Processing methods are commented out, and there is no Event Consumer AF.
- **NWDAF:** not provided. open5gs, which the 5GMS AF builds on, has no NWDAF, so there is no consumer at R5.
