<h1>Public Warning Systems</h1>
</div>
</div>

<ProjectSlide image="/assets/images/projects/emergency-alerts-reference-tools.png" alt="5G Broadcast - Emergency Alerts: Reference Tools slide">

The tools enable authorities and broadcasters to distribute alerts to all receivers in a coverage area simultaneously (without requiring a data connection or active SIM) using the Cell Broadcast Service (CBS) transported over LTE-based 5G Broadcast, also known as Further evolved Multimedia Broadcast Multicast Service (FeMBMS). The work builds on top of the 5G Broadcast - TV and Radio Services platform and has been demonstrated in broadcast network setups; for the current implementation status, see the caveat on the [Implementation Detail](./implementation) page. To see one assembled scenario already running, see the [Tutorials](./tutorials).

</ProjectSlide>

**Implemented specifications:** ETSI TS 103 720 (5G Broadcast System, including CBS transport), 3GPP [TS 23.041](https://www.3gpp.org/dynareport/23041.htm) (Technical realization of Cell Broadcast Service (CBS)), [TR 36.976](https://www.3gpp.org/dynareport/36976.htm) (Overall description of LTE-based 5G broadcast).
