## [Emergency Alerts end-to-end setup](./end-to-end)

This guide describes how to transmit emergency alerts over 5G Broadcast to a 5G Broadcast capable device using
the [rt-mbms-tx-for-qrd-and-crd](https://github.com/5G-MAG/rt-mbms-tx-for-qrd-and-crd).

A Cell Broadcast Service (CBS) emergency alert, compliant with 3GPP TS 23.041, transmitted over an SDR-driven 5G Broadcast transmitter and received and displayed on a real 5G Broadcast-capable device (a QRD or CRD receiver), the same public-warning mechanism (ETWS/CMAS alert types) used for earthquake, tsunami and other emergency notifications. Transmitting radio signals is subject to local regulation; only transmit in a shielded environment or under appropriate authorisation.
