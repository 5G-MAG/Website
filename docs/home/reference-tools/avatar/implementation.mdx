:::tip[In short]

- **What the tools are:** reference tools for conversational avatars using MPEG ARF (ISO/IEC 23090-39) in a real-time call.
- **Status:** not yet audited. The repositories are private today.
- **Source of this page:** the repository descriptions; no code audit has been done yet.

:::

For what ARF and the call procedures define, see the [Technology](/tech/avatar) and the [Standards](/standards/avatar). For how to run the tools, see the [Tutorials](./tutorials) and the [Developer Exchange](./tutorials#developer-exchange).

## Implementation status

Not yet audited. The repositories are private; see [Early Access](/early-access) to request access. The status of each repository, from its description:

- **rt-avatar-call:** a reference framework for avatar communication; its goal is to demonstrate WebRTC communication using MPEG ARF and the related animation compression.
- **rt-avatar-content:** reference MPEG ARF content for real-time avatar communication.
- **rt-avatar-unity-tracker:** a sample OpenXR tracker for ARF avatar animation in Unity.
