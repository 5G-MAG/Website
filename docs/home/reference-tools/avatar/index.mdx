<ProjectSlide image="/assets/images/projects/avatar-reference-tools.png" alt="Conversational Avatar Communication with MPEG ARF: Reference Tools slide">

Avatars are synthesised digital representations of participants, animated in real time from audio and video input, enabling immersive video calls and virtual presence experiences. The 5G-MAG implementation provides codec, rendering, and streaming tools for avatar communications over 5G networks. For the ARF data model, component breakdown and specification status, see [Implementation Detail](./implementation).

ISO/IEC 23090-39 (MPEG Avatar Representation Format, ARF, not yet a published International Standard: see [Implementation Detail](./implementation) for its current stage), 3GPP [TR 26.813](https://www.3gpp.org/dynareport/26813.htm) (Avatar Representation and Communication, the FS_AVATAR study item, completed in Release 19).

See [Conversational Avatar Communication with MPEG ARF on the Standards portal](/standards/avatar) for version history and 5G-MAG's own standards contributions.
