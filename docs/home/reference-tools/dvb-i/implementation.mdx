:::tip[In short]

- **Status:** not yet audited. The audit will be done on the `main` branch of each repository; until then this page shows the state described by each repository's README.
- **Which specification the code follows:** ETSI TS 103 770, *Service Discovery and Programme Metadata for DVB-I*, with its schemas.
- **DVB-I over 5G:** judged against TS 103 770 clause 9.3, 3GPP TS 26.347 and ETSI TR 103 972 once the audit is done.

:::

For what the specifications define, see the [Technology](/tech/dvb-i). For how to run the tools, see the [Tutorials](/reference-tools/dvb-i/tutorials).

## Implementation status

Not yet audited.

- **rt-dvb-i-application:** a browser DVB-I client that discovers a service list, presents its channels with their content guide, and plays them. Its README marks it as under development.
- **rt-dvb-i-android-application:** a native Android DVB-I client that discovers a service list, presents its channels with their content guide, and plays them with Media3 ExoPlayer. Its README marks it as under development.
- **rt-dvb-i-application-provider:** publishes a DVB-I service list and its content guide, and gives an editor for maintaining them. Its README marks it as under development.
- **rt-dvb-i-service-list-registry:** answers DVB-I client queries with a list of Service List Entry Points. Its README marks it as under development.
- **rt-dvb-i-examples:** runnable examples that bring the DVB-I repositories up together on one machine, publishing and playing a service list. Its README marks it as under development.
- **Exo DVB-I Player:** an Android application that is part of rt-5gms-application; not yet audited.
