<ProjectSlide image="/assets/images/projects/dvb-i-reference-tools.png" alt="DVB-I Services over 5G Systems: Reference Tools slide">

DVB-I defines a common service discovery and selection framework that unifies IP-delivered TV services across access networks. The 5G-MAG implementation covers DVB-I service discovery and selection, and hands off to 5G-MAG's other reference tools for the actual 5G unicast (via 5G Media Streaming, 5GMS) and 5G Broadcast (via Further evolved Multimedia Broadcast Multicast Service, FeMBMS) delivery paths, enabling a seamless hybrid broadcast/broadband TV experience. The service list bootstrap step (via a Service List Registry) is not yet documented — see [Tutorials](./tutorials) for the current gap. For the full architecture and specification mapping, see [Implementation Detail](./implementation).

</ProjectSlide>

**Implemented specifications:** DVB BlueBook A177 / ETSI TS 103 770 (DVB-I service discovery and selection). ETSI TS 103 720 (5G Broadcast) and 3GPP [TS 26.512](https://www.3gpp.org/dynareport/26512.htm) (5GMS) are implemented by the sibling [5G Broadcast](../5g-broadcast/) and [5G Media Streaming](../5gms/) reference tools this project hands off to, not by this project itself — see [Implementation Detail](./implementation).

See [DVB-I on the Standards portal](/standards/dvb-i) for version history and 5G-MAG's own standards contributions.
