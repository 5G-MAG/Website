Before building, check the hardware and Android device requirements on the [Requirements](./requirements) page.

## [V3C Unity Player for Android with DASH Streaming Server](./v3c-immersive-platform-in-android-streaming)

This tutorial provides guidance on building the MPEG V3C Immersive Platform for an Android smartphone and delivering content from a DASH server.

A Unity-based V3C player running on an Android phone, decoding V3C-coded volumetric content and streaming it over DASH (Dynamic Adaptive Streaming over HTTP) from a server you run on your own machine: volumetric video played back on a handheld device rather than only in a fixed lab setup.
