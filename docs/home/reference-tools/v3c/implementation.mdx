:::tip[In short]

- **What the tools are:** a Unity player and a decoder plugin for V3C content (V-PCC and MIV), with test content and scripts to prepare it.
- **Status:** not yet audited. The repositories are marked as under development.
- **Source of this page:** the repository READMEs; no code audit has been done yet.

:::

For what V3C, V-PCC and MIV define, see the [Technology](/tech/v3c) and the [Standards](/standards/v3c). For how to run the tools, see the [Tutorials](./tutorials) and the [Developer Exchange](./tutorials#developer-exchange).

## Implementation status

Not yet audited. The status of each repository, from its README (all three public repositories are marked as under development):

- **rt-v3c-decoder-plugin:** the entry points for decoding and viewing MIV and V-PCC content, including a DASH client for V3C segments.
- **rt-v3c-unity-player:** a Unity package to decode and play V3C content using the decoder plugin, for Windows and Android, with a simple example project.
- **rt-v3c-content:** files to configure and test the Unity player, test content, and tools and scripts to generate V3C bitstreams (V-PCC) and DASH segments.
- **rt-v3c-examples:** a repository with example content and helper files.

Which editions and profiles of ISO/IEC 23090-5 and 23090-12 the tools support has not been audited.
