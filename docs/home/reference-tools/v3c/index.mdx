<ProjectSlide image="/assets/images/projects/v3c-reference-tools.png" alt="MPEG V3C Immersive Platform: Reference Tools slide">

The platform provides an end-to-end pipeline for 3D object and scene delivery, allowing viewers to move freely around volumetric content. According to 5G-MAG, a significant part of the initial contribution came from MPEG member companies including InterDigital and Philips; treat any specific partner attribution as something to confirm against 5G-MAG's own announcements before relying on it externally (see [Implementation Detail](./implementation)). To see one assembled scenario already running, see the [Tutorials](./tutorials).

**Key specifications:** ISO/IEC 23090-5 (Visual Volumetric Video-based Coding (V3C) container and multiplexing, including video-based point cloud compression (V-PCC)), ISO/IEC 23090-12 (MPEG Immersive Video (MIV)), ISO/IEC 23090-10 (carriage of V3C data). The reference tooling is still maturing; see [Implementation Detail](./implementation) rather than treating this list as a fixed implementation status.

See [MPEG V3C Immersive Platform on the Standards portal](/standards/v3c) for version history and 5G-MAG's own standards contributions.
