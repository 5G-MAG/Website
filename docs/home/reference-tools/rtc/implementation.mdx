## What the Reference Tool implements

The RTC Reference Tool is the SWAP v1 reference implementation of TS 26.113 clause 13.2.4: a Node.js signalling server and a client library for the signalling reference point RTC-4s. It is audited on the `main` branch of `rt-3gpp-swap` (2026-10-21). The RTC AF, the Media Session Handler, the ICE function and the other RTC AS functions are not part of it.

- **Implemented:** the SWAP signalling over WebSocket at `/3gpp-swap/v1` with the `3gpp.SWAP.v1` subprotocol; connect, accept, reject, update, close and application messages; matching criteria and endpoint selection; optional integrity and encryption of messages.
- **Needs fix:**
  - The server defaults to plain `ws`, where the specification requires `wss`; the client allows `ws` when its `secure` option is false.
  - Errors are sent as a SWAP response whose description joins the Problem Details title and detail, not as a Problem Details object.
  - A message to an endpoint that never registered is acknowledged, not answered with an error.
  - On a received close the client does not send the accept itself.
  - The reference to the request in a reject is optional.
  - The server prefers the endpoint with the most matching criteria and picks at random only among ties.
- **Not implemented:** handling of the Service Access Information and `swapEndpoints`, processing criteria, checking the application message type, and a client that listens for point-to-point connections.
- **Not shown:** cases that depend on the WebSocket library's own behaviour, which is not part of the repository.
