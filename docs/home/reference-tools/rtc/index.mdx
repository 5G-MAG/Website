<h1>Real-time Media Communication (RTC)</h1>
</div>
</div>

For the moment the RTC work is focused on 5G-RTC, the architecture of TS 26.506 and the protocols of TS 26.113 (which share the provisioning and media session handling APIs of TS 26.510 with 5G Media Streaming), and, in parallel, on SWAP. There is no dedicated Reference Tool for RTC yet. One related repository, the 3GPP SWAP Protocol, is already tracked and listed below. It is shared with the [Conversational Avatar Communication](/reference-tools/avatar) project, which owns it. To help build an RTC tool, see [Contributing](/contributing) or ask in the [developer community](/community).
