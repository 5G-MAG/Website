<h1>Tutorials</h1>
</div>
</div>

The RTC work is focused on 5G-RTC (the architecture of TS 26.506 and the protocols of TS 26.113, which share the provisioning and media session handling APIs of TS 26.510 with 5G Media Streaming) and, in parallel, on SWAP, the signalling protocol of TS 26.113 clause 13.2.4. The only RTC code is the SWAP reference implementation, so the tutorial follows it.

- [Tutorial: SWAP Signalling - register, connect, update and close](./swap-signalling): the SWAP messages between two endpoints through a signalling server, each one checked against the JSON schema of TS 26.113, and the calls of the reference library that send them.

For what the SWAP code implements, see the [Implementation Detail](../implementation) page. For the code, see [Repositories & Releases](/reference-tools/rtc#repositories--releases) on the tool page.
