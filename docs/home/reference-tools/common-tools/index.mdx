You normally arrive here from a specific tool's own setup steps, not by starting here. [Implementation Detail](./implementation) lists which shared helper tool in `rt-common-shared` supports which Reference Tool project. There is no dedicated Tutorials page for Common Tools: these scripts and configs are consumed as steps inside each supported project's own tutorial, not run standalone.

Common Tools is a holding area. Its repositories are being distributed to the projects they serve, and no new content is planned here.
