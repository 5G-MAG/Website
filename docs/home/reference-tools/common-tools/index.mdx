## What it does

You normally arrive here from a specific tool's own setup steps, not by starting here. [Scope](./scope) lists which shared helper tool in `rt-common-shared` supports which Reference Tool project, and [Resources](./resources) has the repository and latest releases. There is no dedicated Tutorials page for Common Tools: these scripts and configs are consumed as steps inside each supported project's own tutorial, not run standalone.
