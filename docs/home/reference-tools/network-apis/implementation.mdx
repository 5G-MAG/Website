<h1>Implementation Detail</h1>
</div>
</div>

:::tip[In short]

- **What the tools are:** example files, tools and configurations for working with CAMARA network APIs, as a client: a browser portal, an MCP server and API collections for Insomnia.
- **Status:** not yet audited.
- **Source of this page:** the repository README; no code audit has been done yet.

:::

CAMARA is an open-source project (Linux Foundation, in collaboration with GSMA) that defines portable network APIs, so that an application can request network behaviour through common interfaces rather than operator-specific ones. For what the APIs and the 3GPP specifications behind them define, see the [Technology](/tech/network-apis) and the [Standards](/standards/network-apis). For how to run the tools, see the [Tutorials](./tutorials).

## Implementation status

Not yet audited. According to its README, the repository rt-camara-examples provides the Dedicated Networks API in the portal and in the MCP server, and Insomnia collections that also cover Quality on Demand and QoS Booking. Which parts of these APIs are covered has not been audited.
