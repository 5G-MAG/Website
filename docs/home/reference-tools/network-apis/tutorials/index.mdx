<h1>Tutorials</h1>
</div>
</div>

CAMARA-compliant API clients that let a media application ask the network directly for what a live production needs, such as a booked network slice for a broadcast at a fixed venue and time window. Two tutorials show the Dedicated Networks APIs in use, each complete on its own:

- [Tutorial: Dedicated Networks Portal - book and manage a network](./dedicated-networks-portal): run the portal against a sandbox, find a service area, reserve a network, give a device access, book in one step and dismantle it.
- [Tutorial: Dedicated Networks MCP Server - use it from an AI assistant](./dedicated-networks-mcp-server): install the MCP server, give it to an AI assistant, and book and release a network by asking.

The [Implementation Detail](../implementation) page has the full CAMARA API coverage table, and [Repositories & Releases](/reference-tools/network-apis#repositories--releases) on the project index lists the repositories.
