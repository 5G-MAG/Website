<h1>Tutorial: Dedicated Networks MCP Server</h1>
</div>
</div>

In this tutorial you install the CAMARA Dedicated Networks MCP server, give it to an AI assistant, and ask the assistant, in plain language, to find a service area, reserve a dedicated network, give a device access to it and dismantle both again.

:::tip[Read the READMEs first]
Read the README of [rt-camara-examples](https://github.com/5G-MAG/rt-camara-examples#readme) and the [MCP server's own README](https://github.com/5G-MAG/rt-camara-examples/blob/main/mcp-servers/dedicated-networks/README.md) before you start. They list what the server needs and every setting.
:::

## Components

In `rt-camara-examples`: the MCP server (`mcp-servers/dedicated-networks`), the management portal and the Insomnia collections.

**You need:** `git`; Python 3.10 or newer with pip; an AI assistant that can use MCP servers, such as [Claude Code](https://claude.com/claude-code); and test credentials for a CAMARA sandbox. The sandbox addresses and the credentials are provided to 5G-MAG members on request.

## 1. Install the server

```bash
git clone https://github.com/5G-MAG/rt-camara-examples.git
cd rt-camara-examples/mcp-servers/dedicated-networks
pip install -r requirements.txt
```

This installs `mcp[cli]` (the MCP framework), `httpx` (the HTTP client) and `pydantic` (input validation). To check that it starts, run it by hand:

```bash
python server.py
```

The server writes one line to standard error and then waits for a client:

```
[camara-mcp] Starting | API root: http://localhost:9091/ | Auth: NO TOKEN
```

Press Ctrl+C to stop it. An MCP client starts the server itself, from the configuration in section 3.

## 2. Get a token

The server calls the sandbox with a bearer token. Request one with your client ID and secret from the token endpoint you were given (`<TOKEN_URL>`).:

```bash
curl -s -X POST <TOKEN_URL> -d grant_type=client_credentials -d client_id=<CLIENT_ID> -d client_secret=<CLIENT_SECRET>
```

The answer is a JSON document; copy the value of `access_token`. It is valid for one hour (`expires_in` is 3600), so request a new one when it expires.

:::tip[Keep the token and the secret private]
Do not put them in a repository, a screenshot or a chat. The configuration file you edit next holds the token; keep it on your own machine.
:::

## 3. Give the server to an assistant

An assistant starts the server from a configuration block. Save this as `camara.mcp.json`:

```json
{
  "mcpServers": {
    "camara-dedicated-networks": {
      "command": "python",
      "args": [
        "/path/to/rt-camara-examples/mcp-servers/dedicated-networks/server.py"
      ],
      "env": {
        "CAMARA_API_ROOT": "<CAMARA_API_ROOT>",
        "CAMARA_ACCESS_TOKEN": "<the access_token you copied>"
      }
    }
  }
}
```

Replace the path with the real path of `server.py`, `<CAMARA_API_ROOT>` with the base address of your sandbox, and the token with yours. Then start Claude Code with the server:

```bash
claude --mcp-config camara.mcp.json
```

The server's 12 tools are now available to the assistant, with the prefix `mcp__camara-dedicated-networks__`. Check it with the first question of the next section: the assistant calls `camara_list_profiles` and lists the profiles.

## 4. Ask the assistant

Ask in plain language. The assistant chooses the tools; these are the questions that take you through a full cycle, with what to expect.

1. **"What network profiles are available?"** The assistant lists the profiles with their id, device limit, throughput and QoS profiles (`camara_list_profiles`).
2. **"Find service areas at latitude 48.8467, longitude 2.2530."** It lists the areas that cover the point, and a link for each to view it on a map (`camara_retrieve_service_areas`). Open a link to see the area on geojson.io.
3. **"Create a dedicated network using the profile called profile1 in the Roland Garros Tennis Courts area, from 2026-10-20T17:00:00Z to 2026-10-20T18:00:00Z."** Give the window as start and end times with a time zone, starting now or later. The assistant reserves the network and answers with its id and status **REQUESTED** (`camara_create_network`).
4. **"What is the status of network `<id>`?"** Within a few seconds the status moves to **RESERVED** or **ACTIVATED**; ask again if it still says **REQUESTED** (`camara_get_network`).
5. **"Grant phone number +1234567890 access to network `<id>`."** It creates the access, with status **REQUESTED**, and gives its id (`camara_create_access`).
6. **"Is access `<id>` granted yet?"** The status becomes **GRANTED**, or **REJECTED** with the reason (`camara_get_access`).
7. **"List all my dedicated networks and their status."** (`camara_list_networks`)

Replace each `<id>` with the id from the earlier answer, or let the assistant carry it over in the conversation.

### Dismantle

Release what you booked, the accesses first:

1. **"Revoke access `<id>`."** (`camara_delete_access`)
2. **"Delete network `<id>`."** (`camara_delete_network`)

Then ask for the list of networks again: the answer is "No dedicated networks found."

## Other ways to use the server

<details>
<summary>Call the tools from a script</summary>

Any MCP client can use the server, so you can try every tool without an assistant. Set `CAMARA_API_ROOT` and `CAMARA_ACCESS_TOKEN` in the environment, then, in the server's folder:

```python
import asyncio, os
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    server = StdioServerParameters(command="python", args=["server.py"], env=dict(os.environ))
    async with stdio_client(server) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            result = await session.call_tool("camara_list_profiles", {"params": {}})
            print("".join(c.text for c in result.content if hasattr(c, "text")))

asyncio.run(main())
```

Every tool takes its arguments in a single `params` object, for example `{"params": {"atLocation": {"latitude": 48.8467, "longitude": 2.2530}}}` for `camara_retrieve_service_areas`.

</details>

<details>
<summary>Use OpenCode</summary>

[OpenCode](https://opencode.ai) reads MCP servers from an `opencode.json` in your project, or globally from `~/.config/opencode/opencode.json`. Add:

```json
{
  "mcp": {
    "camara-dedicated-networks": {
      "type": "local",
      "command": ["python", "/path/to/rt-camara-examples/mcp-servers/dedicated-networks/server.py"],
      "enabled": true,
      "environment": {
        "CAMARA_API_ROOT": "<CAMARA_API_ROOT>",
        "CAMARA_ACCESS_TOKEN": "<the access_token you copied>"
      }
    }
  }
}
```

Restart OpenCode. The tools then have the prefix `camara-dedicated-networks_`, for example `camara-dedicated-networks_camara_list_profiles`.

</details>
