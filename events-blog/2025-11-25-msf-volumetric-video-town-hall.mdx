**When:** 25 November @ 16:00–20:00 CET · **Where:** Online

The Metaverse Standards Forum's Volumetric Media Town Hall brings together experts from across the industry to compare the different volumetric video formats in use today and discuss the practical considerations of implementing them in real products.

Patrick Fontaine, representing InterDigital and the 5G-MAG Reference Tools developer community, presented an update on the MPEG V3C Immersive Platform project — the open-source reference implementation of MPEG's Visual Volumetric Video-based Coding (V3C) standard that 5G-MAG maintains as part of its Reference Tools. The talk covered what was new in the project since the last update and where the implementation was headed next.
